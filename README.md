# UtsavSetu – Digital Ceremonies & E-Greeting Card Platform

## Project Overview

UtsavSetu is a digital ceremonies and e-greeting card platform designed to make the creation and sharing of digital greeting cards simple, attractive, and convenient.

The application provides users with a digital platform for creating and viewing personalized greetings for ceremonies, celebrations, and special occasions.

## Key Features

* Digital greeting card creation
* Personalized greeting content
* Ceremony and celebration-oriented designs
* User-friendly interface
* Responsive design
* Digital card viewing and sharing
* Interactive frontend components
* Easy-to-use navigation

## Setup and Installation

### Prerequisites

Make sure the following are installed:

* Node.js
* npm
* Git
* A modern web browser such as Chrome or Edge

### Step 1: Clone the Repository

```bash
git clone https://github.com/sanskruti2106/UtsavSetu.git
```

### Step 2: Open the Project

```bash
cd UtsavSetu
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start the Application

```bash
npm run dev
```

The terminal will provide a local URL, normally similar to:

```text
http://localhost:5173/
```

Open that URL in your browser.

## Execution

1. Clone the repository.
2. Install the required dependencies using `npm install`.
3. Start the development server using `npm run dev`.
4. Open the URL displayed in the terminal.
5. Use the application through the browser.

## Assumptions

* The application is intended to run in a modern web browser.
